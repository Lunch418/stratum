# Прогресс Stratum Modern

ТЗ: stratum-modern-tz.md. Подробные таблицы: docs/audit.md (функции среды),
docs/verification.md (сверка с оригиналом в Wine), docs/review.md (ревью
безопасности и корректности).

## Сделано
- IDE-проход по рабочему окну (X11): меню Файл..Помощь, DEFAULT.STT, солнечная система, ROBOT; ASCII-пунктуация во всём тексте интерфейса, путь в строке состояния, узкое окно (панели сжимаются, панель рисунка переносится). Подавления oxlint просмотрены: настоящих багов не найдено.
- IDE: oxlint чист (0 предупреждений): ложные срабатывания хуков подавлены с пометкой, лишние выражения в Hierarchy/Graphs переписаны. Обход меню в браузере не выполнен (расширение Chrome недоступно).
- IDE: убраны предупреждения oxlint в SchemeCanvas.tsx и Options.tsx (no-unused-expressions, exhaustive-deps с намеренными зависимостями)
- Окно модели в IDE: окно больше вкладки вписывается целиком (кнопка "Вписано"/"100%" переключает натуральную величину с прокруткой); размер и начало координат - из ядра, ядро не менялось (solar_system сообщает окно 1300x1299, не 625x611)
- Среда сверки: скрипты tools/verify_*.py перед каждым запуском оригинала кладут
  эталонный control.dsk (tools/verify/control.dsk: главное окно 960x1011, не развернуто;
  признак развернутости - байт 0xED, прямоугольник окна - 4 int16 с 0xEF).
- Ядро: язык, компилятор в байт-код 0x0d, интерпретатор, форматы .spj/.cls/.vdr/.stt/.dbm,
  2D-графика, 3D-пространства в рисунках, окна (MDI-модель оригинала), сообщения, гипербаза.
- Сверка с оригиналом (20 тактов, все значения совпали): BALLS, BALLS2, DIFF, GIST, L1, L2, L4,
  MOUSE, PHISICS, PixelAccess, linear_brush, VIDEO, Trigger, solar_system.
  Также: Example.33 440/440, MENU 1012/1012, WRITEAVI 326/338, ROBOT 2615/2615, T80 236/236, IRONCLAD 246/246, EDS_IND 915/916 (последняя строка - GetProjectDirectory: путь стенда `C:\verify`, артефакт, не расхождение).
- Сверка (20 тактов, все значения совпали), добавлено: ENGINE 369/369, Surf3d 302/302, ANATOMY 500/500, L3 774/774, SMO2 3568/3568, HIST3D 302/302, ROBOT2 428/428. Имиджи с расходящимся байт-кодом ядро исполняет по байт-коду (core/src/lang/decompile.rs; 432 из 441 кодов собираются обратно). Сообщение исполняет подсхему получателя.
- Среда (app/): все пункты docs/audit.md, кроме видео, просмотра БД и Ogre3D.
- Дизайн: система токенов "чертежный лист", светлая/темная тема, AA-контраст,
  клавиатурная навигация (app/src/a11y.ts), узкие окна.
- Безопасность: токен сессии, Host/Origin, песочница файлов модели, фаззинг
  разборщиков (core/tests/fuzz_parsers.rs), 21 находка исправлена (docs/review.md).
- Состояния: все 81 файл .stt корпуса читаются, включая старую редакцию DEFAULT.STT
  (переменные по номерам); проект без _preload.stt стартует со значениями DEFAULT.STT.
- Сборка: CI (Linux/Windows/macOS), release.yml -> .deb/.AppImage/.msi/.exe/.dmg.

## Известные баги
- Без снимка в Wine: sclogo (падает оригинал), NUI и TextAnalyser (внешние библиотеки),
  2d/api/Net (нет файла проекта).
- DBF: dBASE читается и пишется (Db* и окно "Таблицы DBF"); нет SQL, индексов, MEMO, DbBrowse.
- Звук: Audio* через Web Audio (WAV/MP3/OGG, что декодирует WebView); MIDI и MOD не играют.
- Нет движка: Ogre3D, запись AVI - вызовы считаются и показываются
  плашкой "функции, которых здесь нет".
- Ревью (docs/review.md): 31 находка, открытых высокой серьезности нет; оставлены низкие -
  O(n^2) при загрузке огромного рисунка, запись модели во всю папку проекта (по ТЗ).
