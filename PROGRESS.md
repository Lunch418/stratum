# Прогресс Stratum Modern

ТЗ: stratum-modern-tz.md. Подробные таблицы: docs/audit.md (функции среды),
docs/verification.md (сверка с оригиналом в Wine), docs/review.md (ревью
безопасности и корректности).

## Сделано
- Ядро: язык, компилятор в байт-код 0x0d, интерпретатор, форматы .spj/.cls/.vdr/.stt/.dbm, 2D и 3D графика, окна (MDI-модель), сообщения, гипербаза, DBF/SQL, AVI-видео.
- Сверка с оригиналом в Wine (итоговый прогон, 20 тактов, 40 проектов): почти все примеры совпали полностью; остатки - артефакты стенда, список в docs/verification.md. Исправлено в этом проходе: шкала прозрачности 0..1 (PNG), GetAngleByXY 0..2*pi (PINBALL_).
- Ogre3D (core/src/runtime/ogre.rs, docs/ogre.md): все 299 функций; окно рендеринга идет в IDE как окно модели `Ogre3D` (кадр BMP в SVG, обновляется по Root_RenderOneFrame, мышь и клавиатура приходят в модель). Растеризатор: камеры, свет (направленный/точечный/конусный), туман, текстуры BMP/TGA/PNG/JPEG, смешивание, каркас, плоскости, костная анимация со скиннингом (.skeleton), Scene_Load (dotScene), .mesh v1.4+, скрипты .material/.compositor. Пример docs/examples/ogre-cube; сквозные тесты core/tests/ogre_e2e.rs (исходный текст -> кадр -> BMP, кадр проверен через HTTP /frame). Не рисуются частицы, наложения, MovableText, небесный куб, тени, шейдеры; ресурсы в .zip не читаются; сверки с Wine нет. Сомнения по порядку Эйлера и дескриптору Billboard - в docs/ogre.md.
- Среда (app/): все пункты docs/audit.md. Живая проверка десктопа (X11, 1440x900 и 900x700): справка (поиск, тема, картинки), L1, solar_system, ENGINE (3D), все меню, все вкладки, тёмная тема.
- Справка: картинки тем (формулы, графики) показываются через /api/help-image; справка docs/help не в git (оригинал не распространяется), без неё F1 пишет "справка не собрана: make help".
- Дизайн: токены "чертежный лист", светлая/тёмная тема, контраст AA, клавиатура, узкие окна.
- Безопасность: токен сессии, Host/Origin, песочница файлов, фаззинг разборщиков, 38 находок исправлено (docs/review.md).
- Состояния: 81 файл .stt корпуса читается; проект без _preload.stt стартует со значениями DEFAULT.STT.
- Сборка: CI (Linux/Windows/macOS), release.yml -> .deb/.AppImage/.msi/.exe/.dmg; oxlint чист.

- Живой прогон 3D-примеров в десктопе (Surf3d, ANATOMY, HIST3D, Osc3d, ROBOT, ROBOT2, CHOPPER.3D, IRONCLAD, T80, MENU): окна моделей, свет и цвета в порядке. GetSchemeObject("..") возвращает handle объекта схемы (PINBALL_ HObject совпал); MDim выдаёт MinI, MinJ, MaxI, MaxJ (furie совпал, расхождение было не в порядке тактов).
- Лицензионная чистка: дампы справки (docs/lang/functions.*) и ресурсов оригинала (docs/original/) сняты с учёта git и собираются локально.

## Известные баги и пределы
- Без снимка в Wine: sclogo (падает оригинал), NUI и TextAnalyser (внешние библиотеки), Ogre_3D; 2d, api, Net - не проекты; DIALOG - модальное окно.
- Нет движка: запись AVI (вызовы считаются, показывается плашка). Ogre3D: без Wine-сверки (допущения в docs/ogre.md). Видео: BI_RGB, RLE8, MSVC1, Cinepak; другие кодеки OpenVideo = 0.
- DBF: нет QBE, форматов кроме dBASE; индексы хранятся в собственных файлах (определение, порядок строится при открытии), не .mdx/.ndx. Литерал 0 не HANDLE (нужен #0) - как в оригинале.
- Звук: Audio* через Web Audio (WAV/MP3/OGG); MIDI и MOD отрисовываются ядром в WAV (простой синтезатор, не GM-банк; MOD без E6/E5/7/9). Желоба ползунков AudioPlayer рисует SVG модели (ядро).
- Ревью: открытых высокой серьёзности нет; низкие - O(n^2) при загрузке огромного рисунка, запись модели во всю папку проекта (по ТЗ).
