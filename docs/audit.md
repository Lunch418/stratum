# Сверка с оригиналом: что из Stratum 2000 есть в Stratum Modern

Источник по оригиналу — справка `SC3.HLP` (1329 тем: меню, панели, диалоги,
окна) и таблицы компилятора (960 функций). Статусы: **есть** — сделано в новом
интерфейсе; **иначе** — то же назначение, но другим способом; **частично**;
**нет**; **не нужно** — свойство MDI/Windows 98, у которого в современной среде
нет смысла.

## Функции языка (960)

| Группа | Всего | Статус |
| --- | --- | --- |
| Математика, строки, матрицы, массивы, потоки, файлы, системные | 331 | есть (потоки FILE/MEMORY; диалоги без окна отвечают значением по умолчанию и пишут в «Сообщения») |
| 2D-графика и окна | ~215 | есть; видео-кадры (`CreateVideoFrame2d`, `VideoPlay2d`…) — заглушки |
| Интерфейсные элементы (контролы, LB*) | 21 | есть |
| Имиджи и схема (`GetObjectCount`, `GetVarInfo`, `SetModelText`…) | 25 | есть, кроме перестройки схемы на ходу: `CreateObject`, `DeleteObject`, `CreateLink`, `RemoveLink`, `SetLinkVars`, `CreateClass`, `DeleteClass`, `SetCalcOrder`, `Load/SaveObjectState`, `LoadProject` — принимаются без действия и попадают в список «не реализовано» |
| 3D (`*3d`, `3DTOOLS.TDL`) | ~50 | есть, кроме текстур и `CreateObjectFromFile3d` (v3d), `SweepAndExtrude3d` |
| Базы данных DBF (`Db*`) | 49 | заглушки (нет BDE) |
| Анализатор текста | 10 | заглушки |
| Ogre3D (`Root_*`, `Entity_*`, `SceneNode_*`…) | 315 | нет — отдельный движок-плагин; вызовы возвращают 0 и считаются |
| NUI (Kinect), USB-ключи, SMS/почта | 12 | заглушки |

Проверка: `python3 tools/check_functions.py` печатает функции таблиц, для
которых в ядре нет ветки.

## Главное меню

### Файл
| Оригинал | Статус | Где |
| --- | --- | --- |
| Новый (проект / имидж / рисунок) | частично | «Проект ▾ → Новый проект» создаёт пустой проект в памяти; новый имидж — «+ новый» в иерархии; новый рисунок — нет (см. Рисование) |
| Открыть | есть | Ctrl+O, диалог с обзором папок и недавними; `.spj`, `.prj`, `project.json` |
| Сохранить / Сохранить как / Сохранить проект как / Сохранить все | есть | Ctrl+S, «Сохранить как…» — родной формат; «Экспорт…» — `.spj/.cls/.stt` |
| Печатать, Параметры печати | нет | |
| Список закрытых проектов | есть | «Недавние» в диалоге открытия |
| Выход | есть | закрытие окна; предупреждение о несохранённых правках |

### Окна
Каскадом, черепицей, упорядочить иконки, закрыть все, список окон — **не нужно**:
вместо MDI — фиксированная раскладка панелей с разделителями.

### Помощь
Справка по темам и по функции под курсором — **есть** (панель «Справка», F1).

## Панели инструментов

### Стандартная
Новый проект (частично), Открыть (есть), Печать (нет), Удалить (есть),
Вырезать/Копировать/Вставить (нет), Записать/Загрузить default.stt (нет),
Записать все (есть), Записать активное окно в VDR (нет), Информация о системе
(нет), Иерархия/Библиотеки/Сообщения (есть).

### Управление
Пауза, Запуск, Шаг, Сброс — есть; предыдущая/следующая страница (гиперпереходы)
— нет.

### Рисование — есть (вкладки «Рисунок», «Иконка»)
Режим выбора и перемещение с ручками, линия, полилиния, прямоугольник,
скруглённый прямоугольник, эллипс, дуга, текст, группа/разгруппировать,
Z-порядок, правка точек (Ctrl — добавить, Shift — удалить), панорама, зум,
размер листа, цвет/толщина линии и заливка; правки идут в Undo/Redo и в файл
`.vdr`. Нет: вставить из файла, порядок вычисления имиджей.

### Битовый редактор — нет
Пипетка, карандаш, линия, прямоугольники, эллипсы, закраска, распылитель,
ножницы, цвет, сетка — редактирование иконок и растров не сделано.

### Видео, Базы данных — не нужно / нет
### 3D-графика, Трёхмерные примитивы — нет (есть только функции языка)

## Что делается дальше (по убыванию важности)

1. Вставка рисунка из файла (`.bmp`/`.vdr`), параметры листа (фон,
   координаты, окно).
2. Правка: вырезать/копировать/вставить/дублировать имиджи на схеме; поиск по
   всем имиджам.
3. Моделирование: сохранение/загрузка состояния (`.stt`), «по умолчанию».
4. Диалог создания проекта; параметры проекта (шаг, библиотеки); информация о
   проекте; «где используется» для переменной.
5. Битовый редактор иконок; порядок вычислений; контактные площадки; слои.
