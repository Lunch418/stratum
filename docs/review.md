# Ревью безопасности и корректности

Постоянный обзор того, что приходит в `main`: локальный сервер IDE, песочница
файлов модели, разбор чужих файлов, вывод в SVG/JSON, сборки. Модель угроз -
чужая веб-страница в браузере пользователя и чужой проект (`.spj`, `.cls`,
`.vdr`, `.stt`, `project.json`), открытый пользователем.

Серьёзность: **высокая** - чужой файл или страница пишет/читает вне
разрешённого или роняет IDE; **средняя** - отказ в обслуживании, обход
ограничения при особых условиях; **низкая** - надёжность, защита в глубину.

## 2026-09-25 - 2026-09-26

### Что проверено

- `core/src/player/guard.rs`, `mod.rs`: токен (128 бит, сравнение без раннего
  выхода, cookie `HttpOnly; SameSite=Strict`), `Host` против DNS rebinding,
  `Origin` (включая `null`), только POST для изменений, пределы заголовков,
  тела и соединений. Все маршруты `api.rs` и `editor.rs` за токеном; `GET` не
  меняют состояние.
- Вывод модели в IDE: `gfx/svg.rs` экранирует тексты, имена, шрифты, классы
  контролов; цвета и числа - только форматированные числа; JSON - через
  `json_string`. В `app/src`: `insertAdjacentHTML`/`innerHTML` получают только
  SVG ядра; заголовки окон, подписи контролов, диалоги модели, гиперссылки -
  через `textContent` и React. CSP страницы IDE и `tauri.conf.json` - без
  `unsafe-eval` и чужих скриптов.
- Гипербаза (86d0c4f): "запуск приложения" не выполняется - только сообщение;
  "загрузка проекта" - после подтверждения пользователя с показом пути. Поиск
  файлов модели (`find_file`) берёт только имя файла, без пути.
- Песочница файлов модели (`runtime/extra.rs`): `CreateStream`, `FileCopy`,
  `FileRename`, `FileDelete`, `CreateDir`, `DeleteDir`, `GetFileList`,
  `MSaveAs`, `Save/LoadObjectState` - все идут через `sandboxed`. Процессы ядро
  не запускает нигде.
- Разборщики `.cls`, `.vdr`, `.stt`, `.spj`, `.dbm/.bmp`: новый тест
  `core/tests/fuzz_parsers.rs` - обрезки и порченые копии файлов корпуса
  (`STRATUM_FUZZ_SCALE=30` - долгий прогон, ~50 тыс. вариантов), вложенность
  текста имиджа и `project.json`, циклические группы рисунка.
- `unsafe` в `runtime/clock.rs`: раскладка `TIME_ZONE_INFORMATION` верна,
  разбор TZif - через `get`, без индексации за пределы.
- GitHub Actions: в `run:` нет подстановок недоверенных данных (метка
  релиза - через `$GITHUB_REF_NAME`); права токена - см. ниже.
- `npm audit --omit=dev` в `app/`.
